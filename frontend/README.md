# unobio frontend (hackathon prototype)

Visual prototype for team review: horse-leather black / silver / forest green UI.

## Run

```bash
cd frontend
npm install
npm run dev
```

## Screens (top nav)

1. **Input** — PromptBar + specular rim, ghost autocomplete, mode (+), focus, MD depth
2. **Entities** — ambiguous confirm
3. **Progress** — LatticeLoader + pipeline steps
4. **Result** — 3-panel verdict / claims / evidence
5. **Report** — markdown memo + export MD (PDF is not available)
6. **What-if** — insert evidence + before/after diff
7. **Trace** — cost / latency table
8. **Method** — benchmarks transparency

Flow: type query → confirm → progress auto-advances → result.
